# Facebook source status

The project supports Facebook as a source type, but there is currently no claim that the five supermarket pages can be automatically collected.

For each page, the collector must first verify an allowed public interface. If content is unavailable without authentication or if automation would require bypassing a platform control, that source is marked unavailable and the project uses another permitted source.

Target pages:

- Kipper Market Kosova
- Viva Fresh Store
- Meridian Express
- ETC / Elkos Trading Center
- Interex
